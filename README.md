# WorldEaterNotifier Docs

Docusaurus website for the WorldEaterNotifier Fabric mod. The wiki content (English + Spanish) lives in the `docs/` folder and `i18n/es/docusaurus-plugin-content-docs/current/`.

Published to GitHub Pages via the `Deploy to GitHub Pages` workflow on every push to the `docs-page` branch: https://codew4ve.github.io/WorldEaterNotifier/

## Local development

```bash
npm install
npm run start
```

## Build

```bash
npm run build
```

Static output goes to `build/`. The workflow runs this automatically on push.
